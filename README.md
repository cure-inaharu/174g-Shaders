# 17-ISF

VDMXで使うISFシェーダーのコレクションです。シェーダーはこのフォルダに順次追加します。

## シェーダー

- **17-Resize Glitch Custom.fs** — VIDVOXのResize Glitchをベースに、グリッチの間隔、表示時間、変化速度、倍率などを調整できるエフェクト。

## 使い方

`.fs` ファイルをVDMXのISFエフェクトとして読み込み、映像に適用します。各パラメーターはVDMX上で調整できます。

## クレジット

Resize Glitch CustomはVIDVOXのResize Glitchをベースにしています。元のシェーダーのクレジットはファイル内にも記載しています。
